## 2. Concrete Domain Implementation Walkthroughs

### Walkthrough A: Networking (e.g. QL02 TCP vs UDP)
- **Reference Applied:** Reference 2 (Categorical Stacking) + Reference 1 (Glowing Laser Pulse).
- **Opening:** 0–2s hook showing side-by-side gamer screaming at lag vs YouTube video loading smoothly in 4K.
- **Visuals:** Split arena with TCP on top and UDP on bottom. As voiceover explains, TCP sends a glowing 3-step handshake (`SYN -> SYN-ACK -> ACK`), while UDP fires a rapid machine-gun stream of packets directly to the destination.
- **Takeaway Card:** Bottom HUD highlights: `RELIABILITY = TCP | VELOCITY = UDP`.

### Walkthrough B: Databases & Concurrency (e.g. Race Conditions)
- **Reference Applied:** Reference 5 (Tatkal Booking & Mutex Latch).
- **Opening:** 0–3s countdown showing `10:00:00 AM` on a ticket portal with two users clicking at the exact same millisecond.
- **Visuals:** Isolated black spotlight on the ticket database row. When User A acquires the lock, a physical animated latch (`kundi`) slides shut with a crisp click SFX. User B's transaction is blocked with an hourglass `WAITING` status.
- **Takeaway Card:** Highlights: `PESSIMISTIC ROW LOCK (SELECT ... FOR UPDATE)`.

### Walkthrough C: Software Architecture & Code (e.g. Next.js App Router)
- **Reference Applied:** Reference 3 (Clean Glassmorphic Tree).
- **Opening:** 0–3s showing GitHub repository URL transforming into a live visual architectural graph.
- **Visuals:** Clean glassmorphic macOS window. A root node `RootLayout` branches into `(dashboard)` and `(auth)`. Clicking on a node pops up a dark syntax-highlighted code editor preview with line 12 highlighted.
- **Takeaway Card:** Bottom purple badge highlights: `SERVER COMPONENTS = 0 BUNDLE SIZE`.
