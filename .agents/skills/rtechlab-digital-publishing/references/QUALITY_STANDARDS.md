# RTechLab 22-Point PDF Visual & Technical QA Protocol

Before approving any digital publication, the following 22 gates must be verified:
1. [ ] **Metadata Audit**: PDF title, author ("Rahul Sir & RTechLab Team"), subject, and 2027 edition confirmed.
2. [ ] **Zero Blank Pages**: Strict verification that no page has zero or near-zero orphan content.
3. [ ] **Page Count Integrity**: Matches exact stated curriculum target (e.g., exactly 10, 30, 80, or 120 pages).
4. [ ] **Cover Branding**: Official RTechLab logo, circuit seal, edition pill, and author credits present.
5. [ ] **Watermark Inspection**: Diagonal anti-piracy watermark rendered at 3.5%–4.5% opacity on all pages.
6. [ ] **Running Headers**: Crisp logo, chapter name, and page title on every content page.
7. [ ] **Running Footers**: Standard URL, license key, and correct "Page X of Y" on every page.
8. [ ] **Font Embedding**: Inter and Noto Sans Devanagari fully embedded without missing glyphs.
9. [ ] **Hindi Shaping**: Devanagari conjuncts, matras, and ligatures cleanly rendered.
10. [ ] **Vector Sharpness**: Schematics and diagrams rendered as crisp vector SVGs/typst shapes (no pixelation).
11. [ ] **Callout Alignment**: Padding, borders, and color coding strictly consistent across all boxes.
12. [ ] **Figure Numbering & Captions**: Every diagram has an official figure label and source note.
13. [ ] **Code Block Formatting**: Monospace syntax highlighting with high-contrast background.
14. [ ] **Table Geometry**: Clear headers, zebra striping, and no horizontal overflow beyond page margins.
15. [ ] **Table of Contents**: Clickable internal bookmarks linking directly to corresponding chapters.
16. [ ] **External Links**: Verified HTTPS links to official RFCs and documentation.
17. [ ] **QR Code Error Correction**: High-contrast, level-H error correction scannable on mobile cameras.
18. [ ] **QR Destination Verification**: QR decodes to the exact matching chapter practice URL.
19. [ ] **MCQ Bank Accuracy**: All answer keys independently verified against technical standards.
20. [ ] **Explanation Depth**: Every question includes why the correct answer is right and why distractors fail.
21. [ ] **Print Margins**: Minimum 15mm clearance from physical paper edges for home/office printing.
22. [ ] **Light Theme Standard**: White/light paper background (`#FDFDFE`) for eye comfort and ink saving.
